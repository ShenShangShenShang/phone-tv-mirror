# 快速开始

五分钟内把第一屏投上去。出问题直接跳到最后一节。

---

## 前置条件

- 电视和手机连**同一个局域网**（同一个路由器；不要一个连 WiFi、一个连 4G）。
- 路由器关掉「AP 隔离 / 访客网络隔离」，否则两台机器互相看不见。
- 电视装得下 APK（能 `adb install` 或有 U 盘安装入口）。

---

## 电视端

1. 安装 `01-APK/投屏电视端_v1.0.apk`。
2. 打开它一次即可（这页黑底，中间会有状态文字）。监听和发现都跑在常驻服务里，
   **界面退不退都无所谓**，电视照常显示桌面、VLC、HDMI 都行。
3. 装好之后开机自启（收 `BOOT_COMPLETED`），以后不用再去点图标。

只有手机**真的连上来**时，电视才会把投屏画面切到前台；连接结束 3 秒后自动退回原来的界面。

> 电视端平时不占屏幕、不吃性能。想看服务有没有在跑，打开 App 一次就能看到状态，
> 或者看日志里有没有这两行：

```
监听端口 9000 就绪
自动发现服务监听 9100
```

> 断网、手机关机、投屏软件被杀之后不用拔电源：会话有 15 秒读超时，超时会自己释放连接、
> 回到监听；端口万一出问题也会 1 秒后自动重建。

---

## 手机端

1. 安装 `01-APK/投屏手机端_v1.0.apk`。
2. 第一次打开会**连着弹三个系统权限页**，按顺序都点允许：
   - 通知权限 —— 前台服务的常驻通知要能显示
   - 电池优化白名单 —— 别让系统为省电把投屏掐了
   - 悬浮窗 —— 挂一个 1 像素窗口，让进程被判为"可见"

   这三项是能争取到的全部，没有"后台无限制"这种总开关。全部走完不会再打扰。

3. 点 **「开始投屏」**：

```
点开始
  → 自动广播搜索电视（约 2 秒，不用手填 IP）
  → 找到后弹系统录屏授权
  → 点"允许"
  → 电视上出画面
```

4. 投上之后手机可以退回桌面、切别的 App，画面继续跟着走。通知栏会出现一条
   **「投屏到电视 · 正在投屏 1280x576 · 音量 N%」**，点它回到 App。

---

## 确认真的在投

| 位置 | 该看到什么 |
|---|---|
| 电视屏幕 | 手机画面，等比居中 |
| 手机通知栏 | `正在投屏 1280x576 · 音量 15%` |
| 手机 App 状态卡 | `投屏成功，正在传 ...` |
| 电视端日志 | `手机接入 <手机IP>` → `画面参数 ...` → `解码器已启动` |

---

## 停止

- 手机端点「停止投屏」，或者从通知回 App 再点。
- 投屏一停，**常驻通知会跟着消失**；断开（网络掉、电视端退出）也一样会消失。

---

## 找不到电视 / 连不上

按这个顺序查，基本能在前两条定位：

1. **电视端进程还在不在**。新版本是常驻服务，界面不在前台也会应答发现广播；
   真不正常的是整个进程被杀了（长按主页键清理、或刚卸载重装还没打开过一次）。
   查一下：`adb shell "ps | busybox grep tv.debloat"`。
2. **网段是不是同一个**。手机 WiFi 列表里看的网关和电视的 IP 前三段要一致。
3. **路由器有没有开 AP 隔离**。开了的话两台机器物理上互相看不见，只能换网或者关掉。
4. **是不是点了两次开始**。本版已经做了防护（新会话会把旧会话请走），但如果日志里
   仍然出现两行紧挨着的 `连接电视`，把日志发出来。

手机端日志有两个取法：

```
http://<手机IP>:9999/file     落盘的日志（App 进程死了也还在，最新在最后）
http://<手机IP>:9999/         内存日志（最新在最上面）
```

App 没在跑时这两个地址会拒绝连接，那就只能 `adb logcat -s MIRRORSEND`。

电视端日志：

```bash
adb shell "logcat -d -s TVMIRROR | busybox tail -n 25"
```

正常该像这样：

```
手机接入 10.x.x.x
画面参数 576x1280，CSD 29 字节
显示区 486x1080（画面 576x1280）
解码器已启动
手机设定音量 15%
音频解码器已启动
```

异常长这样：

```
未知握手: <乱码>          → 手机端写出去的包是残缺的，通常是两条会话在打架
会话结束: java.io.EOFException  → 网络断了或手机端线程退出了
显示面未就绪              → 电视端 Surface 没准备好，重开一次电视端 App
```
